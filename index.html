How it works
  • Forward pass. Each neuron computes a = f(w·x + b). Hidden layers use the chosen activation, and the output uses a sigmoid to give a probability.
  • Backpropagation. With sigmoid + binary cross-entropy the output error simplifies to prediction − target. The chain rule pushes that error backwards: each layer's error is the next layer's error × weights × the activation's derivative.
  • Verified with gradient checking. The test suite compares every backprop gradient with a numerical central-difference estimate, and they agree to within 10⁻⁴.
  • Why hidden layers matter. With no hidden layer (or a linear activation) the model is logistic regression and can only draw a straight line. The tests prove it fails on XOR, and adding hidden layers solves it.
  • Optimizers. Plain SGD steps straight down the gradient. Momentum keeps a running velocity to roll through noisy, zig-zagging gradients. Adam adapts a separate step size for every parameter from bias-corrected running averages of the gradient and its square. Try the spiral with each one.
  • Initialisation and regularisation. He initialisation for ReLU and Xavier for tanh/sigmoid keep signals from exploding or vanishing, and L2 weight decay fights overfitting (watch the test loss).
